# Чубу — конфигуратор заказа

Статический сайт на React и TypeScript. Запускайте через HTTP-сервер, например `python -m http.server 8000`, или разместите на GitHub Pages. При прямом открытии HTML браузер может запретить чтение файлов модели.

React-исходники находятся в `src/`, команда `npm install` и `npm run build` создаёт браузерный `app.js`. Модель корпуса `assets/chubu.stl` загружается с сайта. Каталог эмоций и изображения находятся в `assets/`.

Заставка рисуется кодом и шрифтами из приложения (`src/core/splashRender.ts`, `splashFonts.json`). Мелодии событий и ноты взяты из `src/core/setup.ts`, звуки анимаций из каталога прошивки, 8 кГц, 8 бит, моно. В браузере синтезированные мелодии могут звучать иначе, чем пищалка. Логотип, загруженный для заставки, клиенту необходимо дополнительно прикрепить к сообщению в Telegram.

Отправка заказа копирует готовый текст и открывает чат `@LastJoudas`. Посетитель вставляет текст и отправляет сообщение в Telegram. Если автоматическое копирование не удалось, заказ можно скопировать из текстового поля на странице. Сайт не хранит заявки, а данные клиента не передаются в ссылке.

Цены, состав комплектаций, цвета и настройки находятся в `src/main.tsx`. Цвета корпуса предложены как варианты интерфейса и должны быть подтверждены продавцом. Стоимость доставки уточняется отдельно.
