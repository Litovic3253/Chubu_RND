# Чубу — конфигуратор заказа

Статический сайт на React и TypeScript. Запускайте через HTTP-сервер, например `python -m http.server 8000`, или разместите на GitHub Pages. При прямом открытии HTML браузер может запретить чтение файлов модели.

React-исходники находятся в `src/`, команда `npm install` и `npm run build` создаёт браузерный `app.js`. Модель корпуса `assets/chubu.stl` загружается с сайта. Каталог эмоций и изображения находятся в `assets/`.

Заставка рисуется кодом и шрифтами из приложения (`src/core/splashRender.ts`, `splashFonts.json`). Мелодии событий и ноты взяты из `src/core/setup.ts`, звуки анимаций из каталога прошивки, 8 кГц, 8 бит, моно. В браузере синтезированные мелодии могут звучать иначе, чем пищалка. Исходный файл логотипа отправляется вместе с заказом через Cloudflare Worker и Telegram-бота.

Клиент нажимает «Отправить заказ» на сайте. Cloudflare Worker передаёт продавцу в Telegram исходное изображение как файл и полный текст заказа ответом к нему. Заказ без изображения отправляется текстом. Токен бота и ID получателя хранятся как секреты Cloudflare, а не в исходниках сайта.

Цены, состав комплектаций, цвета и настройки находятся в `src/main.tsx`. Цвета корпуса предложены как варианты интерфейса и должны быть подтверждены продавцом. Стоимость доставки уточняется отдельно.


Worker подключён к сайту. Инструкции по настройке — `worker/README.md`.
