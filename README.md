# Чубу — конфигуратор заказа

Статический сайт. Все файлы в корне репозитория; запускать через HTTP-сервер, например `python -m http.server 8000`, и открыть `http://localhost:8000/`. При прямом открытии HTML каталог анимаций и STL могут быть недоступны из-за ограничений браузера.

Для 3D-просмотра загружается Three.js с jsDelivr. Остальные файлы, в том числе модель STL и изображения анимаций, находятся в `assets/`. Если библиотека или WebGL недоступны, клиент по-прежнему может выбрать цвет.

Отправка заказа открывает переписку с `@LastJoudas` с готовым текстом. Посетитель сам нажимает отправку в Telegram. Сайт не хранит заявки, не требует бота и не гарантирует их получение, пока посетитель не отправит сообщение. Контактные данные передаются в ссылке Telegram при открытии чата.

Цены и состав комплектаций находятся в `index.html`, цвета — в `app.js`. Цвета корпуса предложены как варианты интерфейса и должны быть подтверждены продавцом. Стоимость доставки уточняется отдельно.
