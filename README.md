# Чубу — конфигуратор заказа

Статический сайт на React и TypeScript. Откройте `index.html` из скачанной папки или запустите через HTTP-сервер, например `python -m http.server 8000`.

3D-просмотр и каталог эмоций включены в `app.js`, внешние CDN не нужны. Исходная модель STL и изображения анимаций находятся в `assets/`. Исходный React-код находится в `src/main.tsx`. Для пересборки выполните `npm install` и `npm run build`. Если WebGL недоступен, клиент по-прежнему может выбрать цвет. Предпросмотр заставки схематический, а тембр браузера может отличаться от пищалки на устройстве.

Отправка заказа открывает переписку с `@LastJoudas` с готовым текстом. Посетитель сам нажимает отправку в Telegram. Сайт не хранит заявки, не требует бота и не гарантирует их получение, пока посетитель не отправит сообщение. Контактные данные передаются в ссылке Telegram при открытии чата.

Цены, состав комплектаций, цвета и настройки находятся в `src/main.tsx`. Цвета корпуса предложены как варианты интерфейса и должны быть подтверждены продавцом. Стоимость доставки уточняется отдельно.
