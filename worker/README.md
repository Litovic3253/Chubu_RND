# Отправка заказов через Telegram

Этот Worker подготовлен, но по умолчанию не подключён к опубликованному сайту. Текущий сайт продолжает открывать Telegram и отдельно предлагает отправить логотип. Компьютер продавца не должен быть включён для работы Worker.

Для запуска потребуются аккаунт Cloudflare Workers, Telegram-бот, созданный через @BotFather, и числовой ID личного чата владельца с этим ботом. Владелец должен первым открыть чат с ботом и нажать Start: бот не может первым начать личную переписку. Токен бота хранится только как секрет Worker, не в GitHub или браузере.

1. Активировать Workers в аккаунте Cloudflare и авторизовать Wrangler в этом аккаунте. Развернуть Worker из этой папки (`npx wrangler deploy`); при необходимости настроить `ALLOWED_ORIGIN` в `wrangler.toml`.
2. Добавить секреты командами `npx wrangler secret put TELEGRAM_BOT_TOKEN` и `npx wrangler secret put TELEGRAM_CHAT_ID`, вводя их в терминале без сохранения в файлы или коммиты. Проверить, что бот уже получил Start от владельца.
3. Worker ограничивает частоту запросов по посетителю и общую частоту. Перед публичным включением дополнительно настройте защиту от автоматических заявок: Origin и ограничения частоты не блокируют все прямые запросы.
4. Проверить тестовый заказ с изображением и без него. В `src/orderApi.ts` установить `ORDER_API_URL` в адрес Worker с путём `/order`, пересобрать сайт и опубликовать. Не активировать до успешной проверки реальной доставки.

Заказ с логотипом приходит файлом-оригиналом, а полный текст — ответом к файлу; Telegram ограничивает подпись к изображению 1024 символами. Заказ без логотипа приходит текстом. Если после доставки одной части возникла ошибка, сайт сообщает об этом, чтобы не повторить заказ незаметно.

Запуск локальной проверки: `node worker/test.mjs` из папки `site`. Проверка использует имитацию Telegram и не отправляет сообщения.
